## Image Models

### Image Models

- [Image Models](https://docs.poyo.ai/api-manual/image-series/overview.md): All image generation and editing models available on PoYo, with their model IDs.

#### OpenAI

- [GPT-4o Image](https://docs.poyo.ai/api-manual/image-series/gpt-4o-image.md): The GPT-4o Image API generates images from text or transforms reference images. A separate edit model accepts mask-based edits.
- [GPT Image 1.5](https://docs.poyo.ai/api-manual/image-series/gpt-image-1.5.md): The GPT Image 1.5 API generates or edits images. Output size is 1024x1024, 1024x1536, or 1536x1024, and the edit model supports masks.
- [GPT Image 2](https://docs.poyo.ai/api-manual/image-series/gpt-image-2.md): The GPT Image 2 API generates one image from text or edits one or more reference images. Resolution runs from 1K to 4K, with custom sizes up to a 3840-pixel edge.
- [GPT Image 2.5 Flare](https://docs.poyo.ai/api-manual/image-series/gpt-image-2-5-flare.md): The GPT Image 2.5 Flare API generates one image from a prompt or edits up to 16 reference images. It is the faster GPT Image 2.5 option and supports masks, transparent backgrounds, and 1K to 4K output.
- [GPT Image 2.5 Sunburst](https://docs.poyo.ai/api-manual/image-series/gpt-image-2-5-sunburst.md): The GPT Image 2.5 Sunburst API generates one image from a prompt or edits up to 16 reference images. Use it when editing precision matters, with masks, transparent backgrounds, and 1K to 4K output.
- [GPT Image 2.5 Fixed](https://docs.poyo.ai/api-manual/image-series/gpt-image-2-5-fixed.md): Generate or edit images with GPT Image 2.5 Flare or Sunburst at a fixed per-image price by resolution.
- [GPT Image 2.6 Flare](https://docs.poyo.ai/api-manual/image-series/gpt-image-2-6-flare.md): The GPT Image 2.6 Flare API generates one image from a prompt or edits up to 16 reference images. It is the faster GPT Image 2.6 option for quick iteration and supports masks, transparent backgrounds, and 1K to 4K output.
- [GPT Image 2.6 Sunburst](https://docs.poyo.ai/api-manual/image-series/gpt-image-2-6-sunburst.md): The GPT Image 2.6 Sunburst API generates one image from a prompt or edits up to 16 reference images. Use it for detailed visual work and precision-focused editing, with masks, transparent backgrounds, and 1K to 4K output.
- [GPT Image 2.6 Fixed](https://docs.poyo.ai/api-manual/image-series/gpt-image-2-6-fixed.md): Generate or edit images with GPT Image 2.6 Flare or Sunburst at a fixed per-image price by resolution.

#### Microsoft

- [MAI Image 2.6](https://docs.poyo.ai/api-manual/image-series/mai-image-2-6.md): The MAI Image 2.6 API from Microsoft generates one image from a prompt, edits a reference image, or combines up to 5 reference images. It supports 1K and 2K output, custom sizes, and optional web search grounding.
- [MAI Image 2.6 Flash](https://docs.poyo.ai/api-manual/image-series/mai-image-2-6-flash.md): The MAI Image 2.6 Flash API from Microsoft is the faster, lower-cost MAI Image 2.6 option. It generates one image from a prompt, edits a reference image, or combines up to 5 reference images, with 1K and 2K output, custom sizes, and optional web search grounding.

#### MiniMax

- [MiniMax H3 Image](https://docs.poyo.ai/api-manual/image-series/minimax-h3-image.md): The MiniMax H3 Image API generates an image from a prompt or edits up to 16 reference images. It supports 1K, 2K, and 4K output, ten aspect ratios, and custom sizes up to 20 megapixels.

#### Google

- [Nano Banana](https://docs.poyo.ai/api-manual/image-series/nano-banana.md): The Nano Banana API generates or edits images with Google's Gemini 2.5 Flash Image model. It is the earlier fast option in the Nano Banana series.
- [Nano Banana Pro](https://docs.poyo.ai/api-manual/image-series/nano-banana-2.md): The Nano Banana Pro API generates and edits images at 1K, 2K, or 4K. Pro editing accepts up to 14 reference images and can use web search; this page also keeps the earlier Nano Banana 2 model IDs.
- [Nano Banana 2](https://docs.poyo.ai/api-manual/image-series/nano-banana-2-new.md): The Nano Banana 2 API generates or edits images with Gemini 3.1 Flash Image. It supports up to 14 reference images and output from 0.5K through 4K, including native 2K and 4K.
- [Nano Banana 2 Lite](https://docs.poyo.ai/api-manual/image-series/nano-banana-2-lite.md): The Nano Banana 2 Lite API generates images from text or edits reference images. It is the fast Gemini 3.1 Flash Lite Image model, and output aspect ratio can be set explicitly.
- [Nano Banana 2.1](https://docs.poyo.ai/api-manual/image-series/nano-banana-2-1.md): The Nano Banana 2.1 API generates an image from a prompt or edits up to 10 reference images. The default resolution is 1K, and editing can leave the aspect ratio on auto.

#### Flux

- [Flux.2](https://docs.poyo.ai/api-manual/image-series/flux-2.md): The FLUX.2 API generates or edits images. Pro models target high-fidelity production output, and Flex models trade speed against quality. Editing accepts up to 8 reference images, with output up to 2K.
- [Flux Dev](https://docs.poyo.ai/api-manual/image-series/flux-dev.md): The FLUX.1 Dev API generates images from a prompt or edits exactly one reference image. Text-to-image accepts preset ratios, a high-definition square, or a custom WIDTHxHEIGHT size.
- [Flux Schnell](https://docs.poyo.ai/api-manual/image-series/flux-schnell.md): The FLUX.1 Schnell API generates images quickly from a text prompt. Output size can be a preset ratio, a high-definition square, or a custom WIDTHxHEIGHT value.
- [Flux Kontext](https://docs.poyo.ai/api-manual/image-series/flux-kontext.md): The FLUX.1 Kontext API generates images from text or edits one reference image with Pro or Max. Aspect ratios run from 21:9 to 9:21, and edit requests use only the first image URL.
- [Flux 3 Klein](https://docs.poyo.ai/api-manual/image-series/flux-3-klein.md): Generate or edit images with reference images and output up to 4K.

#### Seedream

- [Seedream-4](https://docs.poyo.ai/api-manual/image-series/seedream-4.md): The Seedream 4.0 API generates images from text or edits reference images. Resolution is 1K, 2K, or 4K, and the number of reference images plus outputs cannot exceed 15.
- [Seedream-4.5](https://docs.poyo.ai/api-manual/image-series/seedream-4-5.md): The Seedream 4.5 API generates images from text or edits up to 10 reference images. Output can be 2K, 4K, a preset aspect ratio, or a custom width and height.
- [Seedream-5.0-Lite](https://docs.poyo.ai/api-manual/image-series/seedream-5-0-lite.md): The Seedream 5.0 Lite API generates images from text or edits up to 10 reference images. Output can be 2K, 3K, a preset ratio, or a custom width and height.
- [Seedream-5.0-Pro](https://docs.poyo.ai/api-manual/image-series/seedream-5-0-pro.md): The Seedream 5.0 Pro API generates images from text or edits up to 10 reference images. Output resolution is 1K or 2K across preset aspect ratios.
- [Seedream-5.0-Flash](https://docs.poyo.ai/api-manual/image-series/seedream-5-0-flash.md): The Seedream 5.0 Flash API generates one image from text or edits 1 to 10 reference images. Resolution is 1K, 1.5K, or 2K.
- [Seedream 5.5](https://docs.poyo.ai/api-manual/image-series/seedream-5-5.md): The Seedream 5.5 API generates an image from a prompt or edits up to 10 reference images. It supports 1K, 1.5K, and 2K output, eight aspect ratios, and transparent PNG backgrounds.
- [Seedream 5.5 Layer Decomposition](https://docs.poyo.ai/api-manual/image-series/seedream-5-5-layerize.md): The Seedream 5.5 Layer Decomposition API splits one image into a base image and up to 99 transparent PNG layers, with layer positions, names, descriptions, and optional text OCR.

#### Grok (xAI)

- [Grok Imagine Image](https://docs.poyo.ai/api-manual/image-series/grok-imagine-image.md): The Grok Imagine Image API generates images from text or edits a single reference image. Supported aspect ratios are 2:3, 3:2, 1:1, 16:9, and 9:16.
- [Grok Imagine Image Quality](https://docs.poyo.ai/api-manual/image-series/grok-imagine-image-quality.md): The Grok Imagine Image Quality API generates images from a prompt or edits one or more reference images. Set the number of output images with n.
- [Grok Imagine Image 2.0](https://docs.poyo.ai/api-manual/image-series/grok-imagine-image-2-0.md): The Grok Imagine Image 2.0 API generates images from text or edits one to three reference images. Quality and resolution are selectable, and one request can return up to four images.

#### Kling

- [Kling-o1](https://docs.poyo.ai/api-manual/image-series/kling-o1.md): The Kling O1 API edits images using 1 to 10 reference images and optional character or object elements. Output is 1K or 2K, in preset aspect ratios or auto.
- [Kling-o3](https://docs.poyo.ai/api-manual/image-series/kling-o3.md): The Kling O3 API generates images from a prompt or edits 1 to 10 reference images. Resolution is 1K, 2K, or 4K, and optional elements can lock a character or object.

#### Alibaba

- [Qwen Image 3](https://docs.poyo.ai/api-manual/image-series/qwen-image-3.md): The Qwen Image 3 API generates images from text or from one to three reference images, including Qwen Image 3 Pro. Both support 1K and 2K output, negative prompts, and natural-language edits.
- [Qwen Image 2.1](https://docs.poyo.ai/api-manual/image-series/qwen-image-2-1.md): The Qwen Image 2.1 API generates one image from text, combines up to 10 reference images, or applies a mask edit. Output is 1K or 2K, and backgrounds can be opaque or transparent.
- [Wan-2.7-Image-Pro](https://docs.poyo.ai/api-manual/image-series/wan-2-7-image-pro.md): The Wan 2.7 Image Pro API generates or edits images, using up to four reference images and up to four outputs. Size can be a listed preset or a custom width and height.
- [Wan-2.7-Image](https://docs.poyo.ai/api-manual/image-series/wan-2-7-image.md): The Wan 2.7 Image API generates images from text or edits one to four reference images. Return one to four images at a preset size or a custom width and height.
- [Z-Image](https://docs.poyo.ai/api-manual/image-series/z-image.md): The Z-Image API generates an image from a prompt or edits exactly one reference image. Text-to-image requires an aspect ratio of 1:1, 4:3, 3:4, 16:9, or 9:16.

#### Ideogram

- [Ideogram V4.5](https://docs.poyo.ai/api-manual/image-series/ideogram-v4-5.md): The Ideogram 4.5 API generates images from a prompt or edits one primary image. Edits can add up to four reference images, or three when a mask is set, and high precision keeps unedited pixels.
- [Ideogram Vector 1.0](https://docs.poyo.ai/api-manual/image-series/ideogram-vector-1-0.md): Generate SVG vector graphics from a prompt, with up to five reference images, or convert one image into an SVG.

## LLM Models

### LLM Models

- [LLM Models](https://docs.poyo.ai/api-manual/chat-series/overview.md): All large language models available on PoYo, with the API formats each model supports.

#### API Formats

- [Chat Completions](https://docs.poyo.ai/api-manual/chat-series/chat-completions.md): The General Chat API is a model-agnostic endpoint compatible with the OpenAI Chat Completions request shape. Send a model id and messages, and optionally request a server-sent event stream.
- [Responses](https://docs.poyo.ai/api-manual/chat-series/responses.md): The Responses API is an OpenAI-compatible endpoint for plain text or structured image input. Tool calls and server-sent event streaming are available when the selected model supports them.
- [Anthropic Messages](https://docs.poyo.ai/api-manual/chat-series/claude-messages.md): The Claude Messages API is a model-agnostic endpoint compatible with the Anthropic Messages format. It accepts single-turn or multi-turn text and image input, with streaming and tool use shown in the page examples.
- [Gemini Native](https://docs.poyo.ai/api-manual/chat-series/gemini-native-format.md): The Gemini Native Format API calls generateContent and streamGenerateContent. Requests use contents and parts, including text and inline image data.

#### Models

- [OpenAI](https://docs.poyo.ai/api-manual/chat-series/openai.md): Call OpenAI GPT-6, GPT-5.6, and GPT-5 series models through the Responses or Chat Completions endpoint.
- [Anthropic](https://docs.poyo.ai/api-manual/chat-series/anthropic.md): Call Anthropic Claude 5.5, 5, and 4 series models through the Anthropic Messages or Chat Completions endpoint.

- [Tripo3D P1](https://docs.poyo.ai/api-manual/3d-series/tripo-p1-3d.md): The Tripo3D P1 API generates a low-poly 3D mesh from a text prompt or one object image, with optional textures. The documented face budget stays within the low tens of thousands, and a successful task can return a GLB.

An optional ISO 639-1 language code can enforce the language, and timestamps can be returned as a separate file.
- [ElevenLabs TTS Turbo v2.5](https://docs.poyo.ai/api-manual/music-series/elevenlabs-tts-turbo-2-5.md): The ElevenLabs TTS Turbo v2.5 API converts up to 40,000 characters of text into speech with a selectable voice, speed from 0.7 to 1.2, and an optional ISO 639-1 language code. - [ElevenLabs V4 TTS](https://docs.poyo.ai/api-manual/music-series/elevenlabs-v4-tts.md): The ElevenLabs V4 TTS API converts up to 5,000 characters of text into speech with voice, stability, and similarity controls, plus an optional language code. Choose one of 19 audio formats, and optionally receive timestamps as a separate file.
- [ElevenLabs V4 Turbo TTS](https://docs.poyo.ai/api-manual/music-series/elevenlabs-v4-turbo-tts.md): The ElevenLabs V4 Turbo TTS API converts up to 5,000 characters of text into lower-latency speech with voice, stability, and similarity controls. Choose one of 19 audio formats, and optionally receive timestamps as a separate file.

- [Gemini 3.8 Flash Lite TTS](https://docs.poyo.ai/api-manual/music-series/gemini-3-8-flash-lite-tts.md): The Gemini 3.8 Flash Lite TTS API converts a transcript or a two-speaker dialogue into WAV speech using preset voices and optional style instructions. The complete input is limited to 8,192 tokens.
- [Gemini 3.8 Flash TTS](https://docs.poyo.ai/api-manual/music-series/gemini-3-8-flash-tts.md): The Gemini 3.8 Flash TTS API converts a transcript or a two-speaker dialogue into WAV speech using preset voices and separate style instructions. The complete input is limited to 8,192 tokens.

#### xAI
